# AlgoritmosDeBusquedayOrdenamiento-JD23
1 - Seleccionar uno de los siguientes tamaños para el arreglo:
PEQUENO = 100;
MEDIANO = 1000;
GRANDE = 10000;
y seleccionar uno de los tres metodos de generacion de datos para las pruebas que son:
generarAleatorio(int tamanyo) - Datos aleatorios
generarOrdenado(int tamanyo) - Datos ordenados (mejor caso)
generarInvertido(int tamanyo) - Datos invertidos (peor caso)
---
2 - Hacemos la sustitucion de la porcion respectiva dentro de los metodos del codigo main que corresponden a 
probarOrdenamiento() y probarBusquedas(), cambiamos el tamaño del arreglo a evaluar que se define en el paso 1
y la forma del arreglo a evaluar en los distintos algoritmos mencionados tambien en el paso 1.

3 - ejecutamos el proyecto con la opcion Run (o tambien shift+f10) o click derecho en el archivo main.java y seleccionamos
la opcion que deseamos del menu y obtendremos los resultados proporcionado por el tipo de algoritmo que seleccinamos.
